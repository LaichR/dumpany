# dumpany

A text-generation library for structured output, with easy control over line
width, indentation, and alignment of selected text fragments.
It also lets you place text before or after previously supplied content and
combine text fragments with a delimiter.

It can be used as a Python extension module 
[Python documentation](https://laichr.github.io/dumpany/python/)

Or directly as a Rust crate.
[Rust documentation](https://laichr.github.io/dumpany/rust/dumpany/)

## Repository structure

- [rust/](rust/README.md) — the Rust library.
- [python/](python/README.md) — the Python extension, implemented
  in Rust with PyO3.

See the package READMEs for usage and development instructions.
